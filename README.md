# Is my blue paint your blue paint?

**Demo:** https://dpf01.github.io/blue-paint

The website https://ismy.blue/ lets users judge colors from a spectrum between blue and green. However, it blends the colors between blue and green as if combining blue and green light, so the midpoint is cyan.

I wanted a similar website where the choices bewteen blue and green are instead the colors you would experience if you mixed blue and green paint in varying proportions.

Gemini did all the work: https://gemini.google.com/share/2ccfce1d8c3a
